# Mazharul Islam Sami Notes

A no-sign-in note organizer for trimesters, courses, and notes. Notes are saved in this browser's local storage. Use **Export backup** and **Import backup** to move or restore notes, including JSON exports from the original ChatGPT Sites version.

## Run locally

```sh
npm install
npm run dev
```

## Deploy to Vercel

Import this directory as a Next.js project or run `vercel link` and `vercel deploy --prod` after signing in to Vercel. No environment variables or database are required.
